# TinkerGenie Python Agents Service

Multi-agent AI powered by OpenAI Agents SDK

## Quick Start

```bash
# Install
cd python-agents-service
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# Configure
cp ../agents-sdk/examples/customer_service/.env.example .env
# Edit .env with your OpenAI key

# Run
python main.py
```
